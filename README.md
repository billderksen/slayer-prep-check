# Slayer Prep Check

RuneLite plugin that shows, for your current Slayer task, which items you need and which gear you can put together from your own bank.

## What it does

- Lists the required items for the task (nose peg, rock hammer, boots of stone, ...) and whether each one is with you, in your bank, in your group storage, or missing.
- Builds a gear set per attack style from the items you own, following the "Recommended equipment" tables of the OSRS Wiki. Wiki footnotes are taken into account: full sets such as Elite Void are only used as a whole, and ammo, shields and blessings follow the chosen weapon. Each slot shows the next upgrade from the table.
- Lets you pick the table of a monster that counts for the task (for example Tormented demons for a Greater demons task), or a generic slayer table when the wiki has none.
- Adds a button to the bank that shows only the items for the task, grouped by required items and attack style. This uses the Bank Tags plugin, which is on by default.
- Shows an overlay with what is still missing or in the bank, a chat message when you get a new task, and a ready indicator in the panel.

The plugin does not connect to the wiki or any other server. The wiki data is bundled.

## Setup

Open your bank once, and your group storage if you have one, so the plugin can see what you own. This is remembered per account.

## Configuration

| Option | Effect |
|---|---|
| Show side panel / overlay | Toggle the panel and the overlay |
| Bank tab button | Add the button to the bank |
| Bank tab: selected style only | Only show the style selected in the panel |
| Chat message on new task | Announce required items you are not carrying |
| Style order | Order of the style tabs, e.g. `Melee, Ranged, Magic` |

The Kourend & Kebos elite diary and the Slayer helmet perks are read from the game.

## Updating the wiki data

`src/main/resources/com/slayerprep/gear.json` is generated by `tools/fetch_wiki_gear.py` (Python 3, no dependencies):

```bash
python3 tools/fetch_wiki_gear.py -v --out src/main/resources/com/slayerprep/gear.json
```

Wiki names that are not items (God blessing, Barrows equipment, ...) are mapped to items in `aliases.json`. A workflow regenerates the data monthly and opens a pull request when it changed.

## Building

```bash
./gradlew build   # compile and test
./gradlew run     # RuneLite in developer mode with the plugin
```
